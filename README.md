# Practical Datasets for Visualization

Clean, tidy, documented datasets built from public sources, ready to drop into Tableau, Power BI or any BI tool.

Every dataset lives in `datasets/<name>/` and includes:
- one or more **CSV** files (UTF-8, one header row, `snake_case` columns, ISO dates `YYYY-MM-DD`, plain numbers with units in the column name)
- a **README** with the description, sources and licenses, data dictionary, caveats and dashboard ideas
